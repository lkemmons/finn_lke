# Versions

Latest version is always "main" branch.  Milestone versions are tagged and listed below.

### finn2.9

FINNv2.5 preprocessor rewritten into completely python.  Results near-identical to FINNv2.5.

v2.9.1: uses v2.5 emission factors

v2.9.2: uses updated emission factors based on NEIVA 

### finn2.5.2

tagged version for [Wiedynmyer 2013](https://doi.org/10.5194/egusphere-2023-124)

libraries in preprocessors updated

### finn2.5.1

algorithm switches for forested region vs others

### finn2.4-preproc1.3

NRT support 

### finn2.2-preproc1.0

tagged version which was used for [the State of Texas AQRP project 18-022](http://aqrp.ceer.utexas.edu/index.cfm).
